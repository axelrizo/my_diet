# MyDiet

## Tech Stack

- Elixir 1.19.5
- Erlang 28.3.1
- NodeJS 25.4.0

## Quick Setup

1. Install asdf tool version manager [asdf - Docs](https://asdf-vm.com/guide/introduction.html)
2. Enter with your console to the project folder then:
   ```cdm
   asdf install
   ```
3. Install the docker images
   ```cmd
   docker compose build
   ```
4. Run the containers
   ```cmd
   docker compose run
   ```
5. Run the phoenix server
   ```cmd
   mix phx.server
   ```
